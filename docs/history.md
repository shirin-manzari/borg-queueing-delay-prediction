# Repository history

This Git history was reconstructed on October 25, 2026 from the completed
project snapshot. The project was developed without Git during November and
December 2025, according to its author.

Commits group the existing files into development stages: setup, trace schemas,
validation, features, baselines, analysis, training, evaluation, pipeline
integration, result templates, and documentation. Their author and committer
dates are approximate dates within that development period, not recovered
timestamps. Intermediate commits are organizational milestones and do not
represent recovered historical versions of the code.

The result files currently contain templates pending a verified local run;
their inclusion does not establish that experiments ran on the commit dates.
